---
title: Installation
description: Install Maestro Deck on macOS, Linux, or Windows.
---

To install Maestro Deck on your machine, nothing simpler, use the commands below depending on your OS to install the client needed to create, maintain, and run your tests locally before submitting them through our cloud platform.

<Callout type="info">
  You can absolutely just create, maintain, and run your tests in a fully local way, with no need for the cloud platform, it's free.
</Callout>

## Linux/macOS

```bash
curl -fsSL https://maestrodeck.cloud/install | sh
```

## Windows

Install directly from our download page:

[https://maestrodeck.cloud/solutions/maestro-deck](https://maestrodeck.cloud/solutions/maestro-deck)

If you run into any issues, head over to [https://maestrodeck.cloud/solutions/maestro-deck](https://maestrodeck.cloud/solutions/maestro-deck) to download the software.

Once the software is installed on your machine, it's time to get creative with your tests in the rest of the documentation!
